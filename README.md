**선정 배경**
의료 데이터의 보안 위협 증대에 따라 민감 정보를 안전하게 보호하고, 서비스 연속성 보장을 위한 고가용성 보안 인프라 구축 역량을 확보하고자 함.

**프로젝트 목표**

## 시스템 아키텍처

- **망 분리**: 보안성 강화를 위해 의료진 / 행정 / DB·로그 / DMZ 구역으로 분리
- **원격 접속 환경**: IPsec VPN 터널을 통해 외부에서도 안전하게 내부 자원에 접근
- **서버 구성**: Web 서버(Apache), DB 서버(MariaDB), Log 서버(LogAnalyzer)
- **접근 제어**: 라우터 ACL로 외부 → 내부 VLAN(의료진/행정/DB·로그) 트래픽 전면 차단, DMZ 웹 트래픽(80번 포트)만 허용
- **최소 권한 원칙**: Web 서버 IP에서만 DB 접근 허용, DB 계정에 SELECT/INSERT 권한만 부여, admin/doctor/medical 계정 분리

## 주요 기능

- 관리자 / 의료진 계정 분리 로그인 및 권한(u_group) 기반 접근 제어
- 병원 정보 시스템(HIS) 실시간 모니터링 대시보드(접속 IP, 활성 사용자 수, 강제 로그아웃/접속 차단)
- rsyslog 기반 Web/DB 서버 로그 통합 및 LogAnalyzer 연동 실시간 로그 분석
- 로그인 성공(INFO)/실패(WARNING) 이벤트 구분 기록 및 반복 로그인 시도 탐지
- 비정상 로그인 5회 시도 시 ALERT 등급 보안 경고 자동 생성 및 관리자 알림

## 보안 체계 전략

- **최소 권한 정책**: 역할 기반 접근 제어(관리자/의료진 계정 권한 분리)
- **방어 계층화**: 네트워크·서버·DB 전 계층에 보안 정책 내재화
- **통합 로그 관리**: 중앙 로그 서버 구축을 통한 무결성 보장 및 실시간 추적
- **사용자 관리 권한 정책**: 퇴사자 계정 즉시 삭제/비활성화, 정기(분기) 및 수시 권한 검토
- **침해사고 대응**: 로그 교차 검증 기반 정밀 분석, 전체+증분 백업을 통한 시스템 Clean 복구
